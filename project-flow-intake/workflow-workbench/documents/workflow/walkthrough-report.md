## 已修正

- 按钮源码与正文的字体栈不同：通过源按钮公开style接口绑定B端基础字体，保留源组件变体和交互，不改组件库工程。
- 同一内容的新修订可能复用旧确认：确认匹配增加修订号校验，不仅比较SHA256。
- 改变关联后恢复原关联可能复用旧确认：加入关联基线版本，需重新确认。
- 确认弹窗打开后后台刷新可能改变待确认对象：清单锁定打开时的修订与指纹；旧清单提交返回冲突。
- 文档保存期间的离开及重复提交：增加同步保存锁、关闭/导航保护；切换文档先清除旧文档视图，避免加载期间编辑旧文件。
- 任务详情结果正文与其他内容宽度不一致：统一任务内容布局，补“执行结果”标题；命令状态中文展示。
- 独立说明页缺页面级标题：修正为唯一H1，读取B端页面标题角色。
