先按交付端接入并记录现有资产与采用依据，再选择复用、局部 Token、组件缺口或基座替换分支。用一条真实路径验证必须保留的行为，记录可调 Token、实际变更和证据。逐节点提交所需产出并确认版本；项目端型、组件选型和 Token 值单独决定。

## 首页响应式与尺寸验证

工作台实例采用 767px 及以下的窄屏标题规则，项目预设中桌面标题 24px、窄屏标题 20px。首页常用操作走 Ant Button 默认尺寸，通过 controlHeight 读取 36px；正文与按钮文字 14px。近期任务卡使用同一结构并让操作区换行，当前只提供默认变体。

### 全站响应式复测

工作台以 1440px 为常用按钮选档示例，达到阈值使用 Ant middle，低于阈值使用 small；表格行内操作和固定方形折叠入口独立。767px 及以下收紧页面标题和弹窗内距，按内容容器宽度重排工具区。浏览器实测首页、任务、文档和设计节点在 1600、1440、1439、768、390px 均无页面横向溢出；按钮分别为 36、36、27、27、27px。390px 标题 20px，弹窗正文内距 16px；其余实测视口标题 24px、内距 24px。

| 正式预设 | 16 / 16px | 16 / 16px |
| 隔离预设仅将 pageInset 改为 28px | 28 / 28px | 16 / 16px |
| 隔离预设仅将 cardPadding 改为 28px | 16 / 16px | 28 / 28px |
