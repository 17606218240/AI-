# 参考网站风格提取与扩展

适用于将参考网站还原为可编辑设计样本、从样本建立风格系统，并用其他参考补充缺少的组件或区块。入口为 `$project-flow-intake`，Figma 操作采用当前可用的 Figma Skills。

## 输入和交付

输入包括主参考网址、目标 Figma 文件、目标页面内容以及需要扩展的区块。结合已有对话确定已知项；没有真实履历时使用明确的内容占位。按任务需要选择代表样本，让字体、色彩、布局、材质、状态及媒体处理得到覆盖。

先采集覆盖本次目标的代表区块和可见状态，读取必要结构及样式；现有样本覆盖不足时再扩大，不默认抓取全站或展开所有媒体。已校准且来源未变的样本按[增量验证](project-start.md#按需读取与增量验证)复用；减少采样不能漏掉本次新增材质、响应式或运行交互。

交付包括来源分析、可编辑校准稿、Token 和组合样式、消费规则的组件、原有及新增区块组成的验证页，以及验收记录。每个产物记录自己的维护源、Figma ID 和采用状态。

## 执行路径

1. 浏览主参考的代表页面和交互，记录视口、实际计算样式、布局尺寸、原始素材、内容层级和观察到的动效。过滤隐藏响应式副本、动画逐字节点和透明容器默认样式对统计的干扰。
2. 在目标文件独立区域还原代表区块。通过当前 Figma 工具发现已有可用资产，保留可编辑文字、容器关系、组件实例及原始内容媒体。截图供对照使用。
3. 由样本归纳基础值、语义角色、组件参数和局部特例。共同职责共享语义变量；同值不同职责可以独立。对渐变、阴影、字体组合、内容宽度、栅格、文字密度和素材处理分别记录适合的载体。保留来源实际数值，尺度归一由目标设计决定。
4. 用归纳后的规则重组样本，确认规则能重现来源的主要视觉关系。
5. 从其他参考提取缺失区块的信息结构。按主参考的文字层级、空间关系、表面、媒体和动效规则重新设计，在相同页面中与原有区块共同验证。
6. 检查同尺寸视觉、单角色改值及恢复、长文案、窄屏和组件复用。涉及运行交互时，按 design.md 的参考交互分支验证实际触发、进度、反向及中断。

## 工具选择

运行网页的首次采集使用 `generate_figma_design`，结构重建使用 `use_figma`。素材需要导入时，优先使用 `upload_assets` 的单次上传 URL，把实际图片上传到已知目标节点。提交成功后在另一调用中重读填充并检查截图，以确认媒体已保存。需要复制内容媒体时采用已提交的 imageHash。

采集失败时记录具体返回，按工具规定轮询及排查。可继续完成独立的样式读取、结构重建和内容资产上传；采集状态保持其真实结果。视频、实时3D和着色器分别记录静帧、媒体或运行表现的交付方式。

## 验收证据

| 维度 | 证据 |
| --- | --- |
| 来源校准 | 同视口截图、代表位置尺寸、字体与素材对照；记录剩余差异 |
| 规则可用 | 单独改变一个语义角色，测量目标消费者及应保持原值的角色，恢复后重读 |
| 扩展成立 | 原有及新增区块同页检查，长文案和窄屏仍可阅读 |
| 可维护性 | 文字可编辑、组件实例保留身份、变量及样式调用可追踪 |
| 运行交互 | 实际实现中的滚动、输入、反向及中断结果 |
