# 工作台设计规范

## 当前采用的 Ant Design Token

2026-11-05 按项目接入流程复核，交付面为本地 B 端 Web，进入组件基座替换分支。现行工作台使用 Ant Design 6.6.6 和 Ant 图标。历史中的 shadcn/Radix 是旧基线，当前构建不加载该组件源码。React 负责页面组合，普通 CSS 负责布局和文档排版。

视觉规范参考 [Ant Design 官方主题配置](https://ant.design/docs/react/customize-theme-cn/)。工作台的可调值在 `src/design-presets/workbench.json`，默认基线在 `src/design-presets/ant-web-default.json`，适配层为 `src/styles/workbenchTheme.ts`，由应用根的 ConfigProvider 和 `--wb-*` 变量共同消费。品牌蓝、页面浅灰、面板白、文字、边框、悬浮、字号、圆角与间距按语义维护。正文和按钮 14px，页面标题 24px，卡片和内容标题 16px，弹窗标题 18px。页面侧距 16px，弹窗内边距 24px。表格使用 Ant 原生状态，内容和操作左对齐。普通悬浮使用中性色，表格选中由 Ant 管理。流程图标 32px。

改品牌值时编辑 Token 源；组件的局部例外先使用 Ant 的公开组件 Token 或语义样式接口。更改后检查表格勾选、节点门禁、弹窗版本切换和窄屏。此套值仅适用于工作台；其他项目按各自交付面重新分流。


生效：2026-11-02。仅适用本工作台全部页面和弹窗；不是所有新项目默认设计规范。具体视觉参数以本文为唯一维护处，其他文档引用，不再复制数值。


## 字体应用与回退

工作台的页面、卡片和弹窗标题，以及正文和按钮，统一读取全局字体族 Token。首选思源黑体简体中文版可变字体；Windows 上的微软雅黑位于系统回退栈。字重仍按当前文字角色设置，页面标题与卡片标题为 550，弹窗标题为 600，正文和按钮为 400。旧表中的微软雅黑是更换首选字体前的浏览器对照样本。

字体资产按字符按需加载。常用拉丁字母、数字、标点和 GB2312 一级汉字优先用本地子集，其他思源黑体已收录字符按需加载完整字体。首选字体资源不可用或字形缺失时，由浏览器按字体栈回退。子集保留可变字重轴，源文件和许可证随工程维护。

Windows Chromium 实测：「开发启动」页首载仅请求常用子集（4,268 个字符，1,059,040 字节），标题 CSS 字重 550，节点说明与刷新按钮 400，三者实际使用子集。额外字符「龘」命中完整思源黑体。完整文件 7,711,988 字节，供按需加载。重建子集使用 `scripts/subset-workbench-font.py`（Python、fontTools 和 Brotli）。

## 字体层级与原系统字体对照

全局字体族由预设的 font 提供，Ant 组件经 ConfigProvider 的 fontFamily 读取，页面排版经 --wb-font 读取。以下为 Windows Chromium 在 1440px 视口的代表样本，窄屏页面标题为 20px。

| 角色 | 字号 | CSS 字重 | 实际字体 | Token 映射 |
|---|---:|---:|---|---|
| 页面标题「开发启动」 | 24px | 550 | 微软雅黑 Bold | page / pageNarrow、pageHeadingWeight |
| 卡片标题「接收业务基线」 | 16px | 550 | 微软雅黑 Bold | section、headingWeight |
| 弹窗标题「开发约束与启动 · 流程说明」 | 18px | 600 | 微软雅黑 Bold、Segoe UI Semibold | dialogTitle → Modal.titleFontSize，fontWeightMax → Ant fontWeightStrong |
| 文档正文 | 14px | 400 | 微软雅黑 Regular、Segoe UI Regular | body、bodyLine；常规字重沿用默认 |
| 弹窗按钮「我已知晓」 | 14px | 400 | 微软雅黑 Regular | body、bodyLine；常规字重沿用 Ant 默认 |

字体族均接入同一全局 Token。CSS 字重与系统字体实际匹配的档位分别记录，550 在本次环境命中微软雅黑 Bold。以上为当前角色值，历史条目保留对应版本的参数。

## 字体与层级

按钮文字14px、行高22px，适用于菜单、表格动作、步骤触发器、弹窗及按钮式链接；小尺寸只改变控件高度/内边距，不缩文字。纯图标按钮提供可访问名称。正文14px；页面标题28px/36px、字重550；辅助信息可用次级字号，但不覆盖按钮规则。

## 布局与留白

顶栏内容、正文、页脚左右16px对齐，全宽、不额外居中限宽。卡片主要内边距16px；弹窗标题/正文/底部操作区内边距24px，主要内容区间距16px。控件内部图标/状态间距按用途设置，不强制所有细节都16px。

节点导航、文档与确认操作分区；文档表格单一查看入口进入阅读/编辑/版本。弹窗固定标题和操作区，正文可滚动，不使长内容撑出视口。

## 外观与操作

中性色。所有元素、伪元素及状态无box-shadow/text-shadow/drop-shadow；键盘焦点保留可见outline。内容区按钮用描边或实心背景，不用无边框且无背景的操作按钮。

侧栏是导航例外：无外框，菜单及侧栏说明入口无描边，用浅色背景区分选中/悬停。折叠按钮位于顶部面包屑左侧。功能按钮、导航链接与状态说明按语义呈现，不凭外观替换交互。

## 组件采用与验收

组件及源码来源只在workbench-implementation.md维护；本规范不重复技术选型。页面通过共享主题和组件实现，局部差异限定适用范围。检查正常、空数据、错误、禁用、选中和弹窗状态，无整页横向溢出，内容可读且键盘可操作。
