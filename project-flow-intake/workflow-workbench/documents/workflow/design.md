# 设计与组件库 · 通用流程定义

范围：通用流程草案，尚未安装为Codex Skill。修改后不自动影响已有项目的采用版本。

## 执行入口

先读对应节点的通用规则；涉及规范文档生成时，进入「规范文档生成约定（内部执行入口）」，核对「当前模板登记与项目采用」后执行。历史试跑与修改记录仅用于追溯，不作为当前参数或已通过状态的来源。已有项目沿自己的采用记录，不自动切换到默认模板最新版。

本次整理（2026-11-07）：合并规范文档生成与迁移的重复验收入口，区分通用方法、默认模板登记、项目采用与历史证据；具体视觉参数回到模板资产维护。仅调整本文，未修改Figma源组件、已安装Skill或业务代码，也未将历史未测项改为通过。

## 节点

### 1. 核对设计基线

用户输入：提供本期端/页面范围、规范/Token/组件库位置及已确认视觉；已有工程补充源码位置。

分析：区分有效规范、参考、草稿与占位模板，核对来源、Token有效值与适用端；当前/历史状态按组件和版本登记，不用整库“已接入/未接入”代替。；明确CSS/JSON/规范/展示页各字段的维护源、生成目标和检查方式；旧说明结合后续决定判读，不按文件时间或截图猜权威。

产物：基线登记：来源/版本、组件采用状态、维护与生成职责、冲突和缺口。

确认：只对有效来源选择、冲突或新视觉方向补决定；已确认基线可沿用。

进入条件：当前范围及有效基线明确，各载体职责可追踪；已有资产复用，缺规范可先探索，占位Token不用于工程。

### 按需分支：无 Token 设计稿归纳

提取与采用分开：先确定本批为保真保留原值，还是按目标项目间距尺度规范化。项目维护基础间距尺度、语义用途、适用端及例外；通用流程不强制8px或其他固定网格。规范化按空间用途选择档位，不能机械取最近值；保留原值证据，调整后检查重排、内容增长及适用窄屏。间距网格不自动约束字号、行高、描边、圆角或媒体比例。

基线核对后，只有本期设计稿缺少可用语义 Token 时才进入。已有设计系统时优先复用，仅归纳缺失角色。一次性交付只整理本期工程所需角色。持续维护的设计稿再执行设计侧绑定。

1. 盘点代表页面、组件和状态，记录来源版本、图层标识、属性、原始值和现有绑定。区分直接读取的事实与 AI 推断。
2. AI 先按用途、作用域和应一起变化的位置归类，再比较数值。页面内距与卡片内距同为 24px 时，可共享基础值。需要独立调整时保留两个语义角色。
3. 优先沿用项目词表。缺省命名采用 `类别/用途/角色[/状态]`，例如 `color/text/secondary`。写入前核对当前变量与项目词表，统一大小写和分隔符，并按用途、作用域、类型及主题含义判断同义项。复用已有变量 ID。同名异义或用途不明时，附图层及状态集中复核。只有稳定的新角色才新增。
4. 在现有组件/Token 映射表补记原始值、语义、复用或新增决定、变量 ID 与绑定结果。对持续维护的稿件，在明确的目标文件中批量绑定无歧义项。无法读取或绑定的属性标为待验证。
5. 在同一批页面和同一基线上运行两次。第一次记录新增、复用、绑定及待复核项。第二次重新读取实际变量和绑定，验收新增变量为零、既有 ID 和绑定保持一致。抽查单变量改值仅影响预期图层，并恢复试验值。仅重算映射时，结果记为映射复测，Figma 写入验收仍待执行。

分支输出沿用现有映射表，接入下一节点核对工程消费路径。

参考提取按本期交付范围检查覆盖。每项值或规则标为已观察、归纳候选或补充设计，并关联来源与状态。参考缺失而本期需要的状态、主题或端按项目规范补齐并验证；远期范围记录缺口。采用状态独立登记，观察事实和候选不能直接推导项目已采用。

### 2. 盘点组件与映射

用户输入：说明代表场景、重点状态和当前任务；无工程时提供首批页面需求。

分析：盘点真实组件、主题/样式、属性和依赖，标注实际运行组件、源码快照、HTML近似或待实现；快照不是独立安装包。；映射记录源/目标标识和指纹、场景/状态及默认/局部覆盖；Token逐项对应工程主题、CSS或组件属性的消费路径与转换。

产物：组件/Token映射及首批覆盖：运行类型、场景、覆盖优先级和工程消费路径。

确认：确认首批覆盖及缺失组件；不为了“完整库”预建无需求组件。

进入条件：本批可同步项定位到真实目标与使用场景；近似/快照不能据此认定视觉或运行行为等价。

### 按需检查：风格特征与承载映射

涉及设计还原、风格迁移或主题替换时，在本节点执行；普通业务调整不额外启动整套风格盘点。先从本批代表样本确定必须保留的风格特征，再开始映射。按实际内容检查填充、描边、渐变、内外阴影、圆角、透明度、字体及间距，记录来源图层/组件、版本和适用状态；不能把未展示的状态或截图推断写成已读取事实。

按用途选择承载方式：可独立调节的数值或颜色用 Token；多层高光、投影等组合可由效果样式或组件承载；依赖图层、遮罩、纹理的效果保留对应结构或资产。不要求全部效果 Token 化，也不要求所有卡片具有同一种表面效果。具体参数和表面角色在项目设计系统维护，通用流程不预设视觉风格或组件基座。

沿用现有映射记录，为每项关键特征登记目标 Token/样式/组件/结构或资产、消费位置及处理结果：已应用、不适用（说明原因）、待确认或待实现。用途不明时提出候选，不自行补造或把缺失效果视为不适用。需要独立变化的角色即使当前同值也分别判断语义；既有词表与查重规则继续适用。

### 按需分支：设计资产草稿与规范库封装

当用户要求提取参考风格、整理可维护设计规范或发布可复用 Figma 库时启用；普通页面任务不强制建库。本分支复用前述提取、命名查重和映射规则，不另起一套流程。先识别以下模式：

| 模式 | 输入与产出 | 进入下一步 |
| --- | --- | --- |
| 草稿 | 从本批设计稿提取已观察值，在设计稿旁整理用途、候选变量、样式、组件及缺口；已有有效资产优先复用 | 用户确认采用的范围后，可进入封装；草稿不自动成为正式规范 |
| 规范库封装 | 已确认的设计资产与明确的目标 Figma 文件；整理真实变量、样式、组件、文档模板及可跳转目录 | 完成绑定与代表页面验证后形成发布候选；实际发布按授权与账户能力执行 |

#### 目标与模板配置

在现有基线/映射记录维护：设计源文件及节点、目标库文件、采用版本和端、产品 Token/样式/组件身份、命名词表、文档主题、文档模板来源及主组件 ID/key、内容类型到模板的对应关系、开放属性和允许调整范围。值未知时明确待补，不猜测组件身份。空目标链接只表示目标位置，不提供视觉基线；从已确认设计源和模板读取。

产品视觉与规范文档视觉独立维护。产品 Token 控制示例组件的风格；文档主题控制页头、说明、表格和目录的风格，不随更换文档主题改动产品示例。不得把某个文件的 Ant 分类、固定页头高度、8px网格或具体字体变成跨项目默认值。

用户可以用自然语言修改模板的允许项、禁止项及适用范围。将明确要求写入上述配置，说明替代关系；只作用于本次的要求不自动升级通用规则。配置与实际 Figma 资产不一致时，先指出差异再按已授权范围修正。

#### 规范文档生成约定（内部执行入口）

适用对象为设计规范及 Token 规范库的目录、说明、参数表与样张等文档呈现，不是产品页面的视觉规范。执行顺序：确定范围 → 读取当前模板与项目资产 → 匹配模板 → 生成或增量更新 → 分层验收 → 同步采用记录并交付。普通文档更新不自动启动 Token 提取、产品组件建库或发布。

#### 设计规范呈现契约（2026-11-08）

用户明确指定为后续设计规范的默认产出方式；取代本分支把参数规范与 Token/语义化展示默认合并的做法。项目后续明确覆盖仍优先，产品值不得从文档模板继承。

- **范围与数值**：只提取本批指定设计稿实际出现的规范参数；保留实际字体、字重、字号、行高、字距、间距、圆角、颜色及不透明度等组合。不得为了凑整或形成常用阶梯补值、改值、抹除真实组合差异。同字号或同基础色可归并展示，但仍保留其实际参数组合与用途。明确要求的类别、阶梯或对照位置缺值时保留空白占位；不得用模板示例值填充，也不自拟缺失档位或未经确认的色阶编号。
- **规范与 Token 分离**：设计规范默认不生成或展示 Token、变量命名、别名、语义角色与代码映射；这些内容仅在用户另行明确要求时进入相应分支。已有变量可作为读值依据，不因生成文档修改变量表。
- **标题与文案**：规范标题使用单一、直接的类别名，如「色彩」「文字」「边距」「间距」「圆角」，不把不同规范合并成「文字、表面与操作」等标题。规范页头使用已采用的 `Docs / Page Header`，填写标题和简短描述并显示描述。页头描述只说明本页规范范围；正文采用「标题＋描述＋内容」或「标题＋内容」，描述按需要保留，不强行为每个模块凑文案。
- **正文内容**：普通规范优先用图形样张、数值及简短描述展示；需要 Token 命名时才单独使用表格。用户明确要求保持原表达的模块（如当前渐变）沿用原结构，不能为统一样式擅自重绘。使用场景简写为「标题」「Hero」「工牌」等；已有表格采用「描述」列，图形卡使用对应描述文字。禁止向阅读正文注入「此数值来源于…」、工具操作限制、生成过程、内部布局参数、来源追溯或实现状态等无关说明。来源、模板采用与验证证据写入维护记录和组件说明，不混入规范阅读正文。
- **色彩归类**：按「主题色、功能色、中性色、带有品牌倾向的中性色、扩展色」组织。文字使用的灰、黑、白及带倾向的近中性色归入相应中性色类别，不单设「文字颜色」或复制同一色值；文字用途仅作描述。只归类并保留实际颜色，后续删除或调值由用户决定，不因去掉独立文字分类而删色。只展示已观察颜色，依明暗排序；有明确原始阶梯身份时才沿用编号。主题/功能用途不明确时不擅自认定。缺失颜色或档位以空白占位表达，不自动插值或套用 TDesign 示例色板。
- **不透明度与渐变**：当前作品集用户已明确授权规范化：黑白基础色使用0%至100%、每10%一档，现有透明度取最近档（正中取较高档），字体、背景、描边共用；普通半透明实色仅使用#000000或#FFFFFF。此项是本项目显式调整，覆盖此前仅提取观察值的限制，不推广为其他项目默认值。统一放在色彩规范。同一基础色只有一个阶梯，字体、背景、图形与描边共用其已观察不透明度的并集；仅基础色不同（如 `#FFFFFF`、`#000000` 或其他实际颜色）才分开。每档以实心色块呈现，标实际色值、不透明度，必要时简写 font/bg/stroke 使用范围；不因用途不同重复生成同色阶梯。实色灰不能推算为未出现的透明度。渐变属于色彩规范，已有模块可原样迁入，避免保留一份独立渐变规范重复维护。
- **文字阶梯**：以实际字号分档排序，样张必须使用该档真实字号，不能所有样张用同一文档字号后只改数字标签。同字号内汇总实际字重（如粗体/中等）和行高，用 `/` 并列实际存在的行高，包括与字号相等的行高；Auto 保留 Auto，不补数值。同档保留不同字体、字重、行高、字距的真实对应组合，不能把汇总值任意交叉组合。每档说明实际用于哪些位置。字体不可加载时保留源字体名称与参数，说明尺寸示意所用文档字体；不改产品稿字体，不声称已还原字形。
- **间距（包含边距）**：边距、内距、外距与元素间隔统一在一份「间距」规范中，按实际使用层级分为元素间距、卡片间距、内容间距、模块间距、页面间距等；只保留设计稿有依据的类别。分类依据实际容器与使用关系，不以数值大小猜测。同一数值可出现在不同类别，各类别内部去重、升序；不生成语义化 Token、用途命名映射或上/右/下/左应用组合，不另保留边距规范。每档用独立实心矩形表示，宽度等于实际数值，统一示意高度，下方标数值与单位，横向排列并按需换行；不用夹元素组合或重复边框卡片。示意高度、排版距离及用户案例数字不是产品参数，不补未观察阶梯。本条替代此前「单一无分类阶梯」及分开维护边距的旧约定。
- **描边**：只记录实际朝向/边、粗细和对齐（内描边、居中、外描边）等几何属性；按这些属性组合查重。颜色、不透明度、纯色/渐变变化不生成新的描边档位，这些参数在色彩规范维护。图形样张可用统一文档示意色增强可读性，但不得改产品描边；未出现的方向、粗细或对齐方式不补。
- **背景模糊**：同时交付直观图形样张和参数表，不能只画效果卡。表格至少列出实际模糊类型和半径（含单位），源资产有其他已观察模式或相关参数时再列入；不拿样张演示用的背景、透明度等数值冒充产品模糊参数，不补默认值。此为用户明确指定的表格例外，不受普通规范仅在 Token 命名时使用表格的默认限制。
- **标注层级**：所有规范移除展示序号与页码序号，保留实际参数和已有资产命名身份。关键数值、描边朝向与内/居中/外对齐等重要标注提高字号与可读性，辅助用途说明保持次级层级；文字样张仍使用真实字号，不因文档强调而改变参数样张。
- **正文精简与留白**：文字字号模块取消装饰性描边；圆角展示卡与样张取消描边，图形适度缩小但保留真实圆角值。圆角按设计稿实际使用范围分为元素圆角、卡片圆角等，各类别内去重、升序，同值确有跨类使用时可分别保留。只展示类别标题、样张和数值单位，删除逐项「圆角／工牌」等语义或用途描述，不按数值阈值猜测分类。当前作品集圆角样张采用160×96、每行最多六档、分类间距120px，仅为文档展示参数。间距规范各分类小模块之间留白统一120px，不是模块内四边Padding或产品间距参数。正文不再重复页头主题或「主题＋阶梯」总标题，保留元素间距、卡片间距、色彩分类等有区分作用的子标题；通过实例标题组显隐处理，不修改默认源组件。
- **排版采用**：页头以默认源 `3:25` 的实际组件、开放属性和显隐规则为准。正文优先实例化下表登记的模块组件；标题组、描述、内容之间的间距及字体、尺寸模式从当前源资产读取。正文父级只负责模块之间的间隔；模块内部负责标题组到内容的间隔，不能再由父级叠加同一留白。一个模块包含连续多张参数表时，它们属于同一内容槽位，不给每张表重复增加无意义标题。
- **组件调用**：只覆盖公开文字、描述显隐和 `Content` 槽位。内容槽位接收本批已有参数表、色阶样张或视觉样张；不能复制模板中的 Blue 色值等示例数据进入项目规范。新模块不可跨文件导入时按下文快照规则处理，登记源/目标身份及同步责任，不冒充远程实例或自动发布。

验收同时检查：页头有简短描述；模块符合两种结构之一；间距符合已采用源；保留实际参数及空白位置；没有 Token/语义化与过程说明混入；长标题、描述显隐和表格增高不会裁切。用户只要求当前设计稿规范时，不额外生成无关页面、组件规范或说明章节。

#### 当前模板登记与项目采用

以下是本工作流维护的默认资产登记，供未指定模板的新任务选择；已有项目以明确采用记录为准。登记用于定位，执行前重读实际组件、公开属性和语义说明；未知版本或未读取的参数标待复核，不按名称或文件时间猜测。
